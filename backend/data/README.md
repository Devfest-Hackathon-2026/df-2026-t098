# IP country data

`dbip-country-lite.mmdb.gz` is the November 2026 DB-IP Country Lite database.
The server uses it to suggest the first display language. It does not return a country code.

- Source: [DB-IP Country Lite November 2026](https://download.db-ip.com/free/dbip-country-lite-2026-11.mmdb.gz)
- SHA-256: `75fe430010f6d38a8c4331c202bf0df6ce3221a6e6d823b9e5a6d951e4cf9758`
- [IP Geolocation by DB-IP](https://db-ip.com), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

When updating the data, replace the archive with a verified Country Lite download and update the
source and checksum above. Keep the attribution and run the locale tests against the new file.
